# 剧情编辑器

剧情编辑器提供独立于原版剧情进度的本地创作草稿。作品按「作品 → 幕 → 分镜 → 命令」组织；每条分镜可插入对白、背景/CG、人物立绘与位置、舞台文字、BGM、音效、等待、转场及当前播放器支持的剧情特效。未知命令以原始文本保留，避免编辑后丢失未支持内容。

## 素材与预览

背景、CG、人物、音乐和音效可从 PRTS 目录搜索，也可上传 PNG/JPEG/WebP 图片或 MP3/WAV/M4A/OGG 音频。图片与音频随作品 JSON 一并打包，SHA-256 用于完整性检查；单项素材上限 32 MiB，作品上限 96 MiB。剧情特效直接使用应用已集成的 FX，不复制到作品。
CG 候选项来自 PRTS 的剧情资源索引；首次打开 CG 选择器时分页读取并在当前创作页内复用，资源图片仍按需临时加载。使用剧情馆「派生为作品」导入现有剧情时，若该篇尚未完整缓存，先按完整缓存流程下载脚本和静态依赖；成功后再进入编辑器，以便音乐、背景和立绘可立即预览。缓存失败时不打开编辑器。

舞台按固定 1280×720 坐标呈现，支持 50%–200% 缩放、空格/放大拖拽平移与双击适配。舞台默认仅显示选中对象的操作手柄，未选中对象以淡轮廓提示并在 hover 时显形；仅舞台文字（`subtitle`）提供右侧调宽与右下角调字号变换框，立绘、背景与 CG 提供位置移动与 6 px 参考线吸附（按住 `Alt` 临时关闭，`Shift` 锁定单轴，拖动时显示数值气泡）。舞台左上角提供对象列表浮层；拖动或点击跨分镜继承的对象时，可二选一「跳转到来源指令」或「在当前分镜插入覆盖指令」。

草稿自动保存在应用专用存储中，同时记录每个分镜/幕的标记颜色与备注，以及作品最近一次打开位置（幕/分镜/指令），重新打开作品自动恢复位置。导出作品会包含本地素材，导出脚本只包含命令；剧本台支持导出台本（TXT）、对白表（CSV）与字幕（SRT）。导入的作品会验证素材摘要和结构。删除作品只删除编辑器草稿，不影响原版剧情或离线缓存。

## 工作区与批量编辑

桌面宽屏提供三个工作区，并保留原有「本地作品」与「作品素材管理」入口：

- **演出台**：左栏常驻三级折叠结构树（作品 → 幕 → 分镜，展示指令数、警告数、标记色与估算时长，支持拖拽重排与右键菜单），顶部提供面包屑逐级导航、`Alt+←/→` 历史前进后退、全局搜索与 `Ctrl+K` 命令面板。指令列表支持单击、`Shift` 连选、`Ctrl/⌘` 增减、全选/反选、右键菜单、`Ctrl+C/X/V` 跨分镜剪贴板、`Ctrl+D` 复制、`Delete` 删除与批量操作条（批量改说话人/复制/删除）。右侧检查器按「内容 / 布局 / 时间与音频 / 高级」分组（高级默认收起），提供坐标 scrub 与居中/重置、时长滑杆、音量 dB 滑杆与静音复位、遮罩色板、枚举分段按钮、媒体缩略图与来源徽标，以及多选混合值统一写入。
- **编排台（故事板）**：按幕分组展示分镜卡片墙（按分镜视觉签名缓存缩略图摘要），显示首句台词、指令数、估算时长、警告徽标、标记色与音频/特效/分支角标；支持同幕/跨幕拖拽重排、小/中/大卡缩放、按「有警告 / 有标记」筛选、多选批量复制/删除、快捷新建分镜及双击返回演出台定位。
- **剧本台（对白表格）**：按序汇总全作品对白与舞台文字，支持行内直接修改说话人与台词、关键词搜索、仅当前幕筛选、全选批量替换说话人、双击定位回演出台以及导出 TXT/CSV/SRT。

手机端（窄屏）维持轻量化形态：提供「演出」与「分镜」切换（不上桌面式多列剧本表格），采用紧凑双行传输条防止位置标签截断，支持长按指令轻量多选与底部属性抽屉，并在「分镜」页以横向卡片快速切换回演出台。

## 当前边界

分支只读图、状态泳道「在此固化状态」、草稿分层版本历史、Web 只读交互包与 MP4 视频导出归属后续阶段，尚未纳入本版本。
