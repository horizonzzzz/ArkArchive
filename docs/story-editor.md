# 剧情编辑器

剧情编辑器提供独立于原版剧情进度的本地创作草稿。作品按「作品 → 幕 → 分镜 → 命令」组织；每条分镜可插入对白、背景/CG、人物立绘与位置、舞台文字、BGM、音效、等待、转场及当前播放器支持的剧情特效。未知命令以原始文本保留，避免编辑后丢失未支持内容。

## 素材与预览

背景、CG、人物、音乐和音效可从 PRTS 目录搜索，也可上传 PNG/JPEG/WebP 图片或 MP3/WAV/M4A/OGG 音频。图片与音频随作品 JSON 一并打包，SHA-256 用于完整性检查；单项素材上限 32 MiB，作品上限 96 MiB。剧情特效直接使用应用已集成的 FX，不复制到作品。
CG 候选项来自 PRTS 的剧情资源索引；首次打开 CG 选择器时分页读取并在当前创作页内复用，资源图片仍按需临时加载。

舞台按固定 1280×720 坐标呈现，可直接拖动背景、人物与舞台文字。预览支持当前分镜、从当前分镜和整段播放；所有读取缺失的 PRTS 媒体都走临时加载路径，不写入剧情缓存，也不保存观看进度或断点。

草稿自动保存在应用专用存储中。导出作品会包含本地素材，导出脚本只包含命令；导入的作品会验证素材摘要和结构。删除作品只删除编辑器草稿，不影响原版剧情或离线缓存。

## 当前范围

当前版本覆盖基础分镜编排、位置拖动、方向键微调、本地素材、PRTS 素材目录、图片缩略图、音频试听、试播自动播放/暂停/重播、撤销/重做、自动保存及作品导入/导出。我的作品面板支持最近修改时间、播放、编辑、重命名、复制和删除；作品素材面板显示引用计数与体积，并可清理未引用素材；剧情馆可将官方剧情派生为独立草稿，编辑器播放不会写入原版观看进度。高级/raw 指令可直接编辑源码，无法解析时保留原指令。时间轴、分支编辑、模板和高级运镜编辑尚未提供。

手机端可以使用底部「创作」入口编辑、试播和导出；由于窄屏空间有限，分镜和命令通过纵向列表编辑，舞台仍维持与桌面一致的逻辑坐标。
