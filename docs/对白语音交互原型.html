播放器层可交互改动点

  1. 顶部工具条为「退出 / 对话记录 / 自动播放 / 控制中心」四键；诊断按钮移出播放器（决策①），入口归入应用设置·网络与节点（见 Tab②）。改动：lib/story_player/ui/story_player.dart 顶栏 Row。
  2. 对话框「语音状态徽标」常驻（决策⑤）：语音开启时始终显示于说话人左侧——待机（灰条 +「语音待机」）/ 朗读中（跳动动画 + 音色 ID）两态；快进与快速模式显示「静音」态；关闭语音或未装包时隐藏。新增轻组件 VoiceBadge，数据来自 DialogueVoice.status 流。
  3. 控制中心为播放器内右侧滑入抽屉（决策③：横屏右侧空间富余，与顶部进度条、底部对话框零重叠，桌面与移动端一致），收纳偏好类功能：播放节奏（模式 / 速度档·仅自动模式可调 / 剧场模式）、四通道音量、对白语音（开关 / 音色试听 / 语音包）。新增 lib/story_player/ui/control_hub_sheet.dart。
  4. 进度条交互保持不变（顶部热区呼出、停顿点刻度、拖动预览）；本原型仅示意位置，点击可跳句。

抽屉打开期间（决策②）：自动播放暂停推进，关闭后自动续播——避免设置过程漏看剧情；手动模式本就无自动推进，不受影响。速度档仅在自动模式下可调（决策④）。长按快进手势只在舞台区生效，与面板按钮无冲突（事件冒泡已在 _FastForwardGesture 中隔离）。

应用层改动集中在设置页：「音频通道」新增对白语音滑杆与语音包管理入口；语音包沿用剧情缓存的下载任务模型（暂停 / 恢复 / 失败原因 / 移动网络提醒）。本页与播放器原型共享同一演示状态——若刚才已下载，此处即显示已安装。

应用层可交互改动点

  1. 「音频通道」新增对白语音第四通道：滑杆样式与既有三通道完全一致。PlaybackSettings 增加 voice 字段（0 即关闭），沿用 copyWith / toJson / fromJson 与 clamp 模式，存储结构不变。
  2. 语音包管理卡片：包状态 / 下载 / 校验 / 删除。下载任务复用 cache_job.dart 任务模型与 file_cache 下载管线（含移动网络提醒与并发控制），文件 sha256 校验通过后原子置为已安装。新增 lib/story_player/data/voice_pack.dart。
  3. 角色语音包（阶段 5）：同一 manifest schema，按包独立下载安装，卸载后自动回落默认包映射；设置页提供「按角色 / 按包」两个管理视角。
  4. 诊断入口迁移（决策①）：播放器顶栏诊断按钮移除；「网络与节点」新增「资源与指令诊断」行，展示最近播放累积的 engine.warnings（未找到音频、暂不支持指令等），供问题反馈排查，常规播放不可见。

三、播放器功能交互改造：三层交互模型

播放器已承载：点击推进、长按快进（2–16x）、进度条（拖动 / 预览 / 精细刻度）、自动播放、对话记录、诊断、剧场模式（引擎级，未露入口）——而 TTS 将再带来开关、音量、角色音色、试听、语音包五组新交互。沉浸式播放器的屏幕与注意力预算有限，继续平铺顶部按钮不可持续。

常驻层

ALWAYS-ON

顶栏四键：退出 / 对话记录 / 自动播放 / 控制中心入口。高频、单状态、一键直达。诊断对用户基本无用（决策①），整体移出播放器。

手势层

GESTURE-DRIVEN

节奏控制全部走既有手势：单击推进、长按快进换挡、顶部呼出进度条。手势零新增、零学习成本，快进期间 TTS 自动静音。

收拢层

CONTROL HUB

所有偏好类功能收进右侧控制中心抽屉：速度档（仅自动模式）、四通道音量、TTS 全家桶、剧场模式——打开即改即生效，即写回设置持久化；诊断整体移出播放器（决策①）。

备选形态对比

右侧滑入抽屉采用

横屏 16:9 右侧空间富余；与顶部进度条热区、底部对话框零重叠；桌面与移动端形态一致；showGeneralDialog / endDrawer 实现成本低（决策③）。

底部上滑抽屉放弃

与底部对话框阅读区纵向抢空间；横屏高度预算紧张，分组多时需内部滚动。

扩顶栏按钮 / 径向菜单放弃

6+ 图标超出沉浸式预算且与原作风格冲突；径向菜单与长按快进手势冲突、可发现性差。

五、决策记录（已确认 2026-11-09）

决策点结论与影响
① 诊断去向移出播放器：顶栏移除诊断按钮；入口归入 设置·网络与节点 →「资源与指令诊断」（engine.warnings 汇总），常规播放不可见
② 面板打开时自动播放暂停推进（engine.setPaused），关闭面板后自动续播；手动模式不受影响
③ 面板形态右侧滑入抽屉：桌面横屏右侧富余，与进度条/对话框零重叠，移动端一致
④ 速度档仅挂自动模式：I/II/III 对应 buttonSpeeds；手动与快速模式下不可调，快速档位不暴露 UI
⑤ TTS 徽标说话人旁常驻：待机 / 朗读中两态；快进与快速模式显示静音态；关闭语音或未装包时隐藏
