数据说明

  • 人物、头像、立绘、档案文本、台词均为 PRTS 真实数据。
  • 出场统计与台词来自 41 / 2061 篇样本剧情 的扫描结果；未出现在样本中的人物显示「待全量索引」。
  • 全量数据将由 P0 数据管线构建（索引种子 + 别名表 + 质量报告）。

值得试的演示点

  • 两类角色：列表与详情中「干员」（头像+职业+星级）与「剧情角色」（AVG 立绘+黄标）的差异化处理。
  • 多立绘：进入阿米娅详情，切换「术师 / 近卫 / 医疗」形态，立绘与画廊随之变化。
  • 异格同体：搜索 维什戴尔 命中 W，详情可切换「W / 维什戴尔」形态——不同干员单位、剧情中同一个人；异格一律人工 form_merge.json 维护（一年才几个，不做自动匹配）。
  • 剧情限定形象：凯尔希详情的立绘画廊有「限定形象 3 张 · 含剧透」折叠——遗尘漫步 WD-7 的旧形象（kaltsn07/08/09），点击展开。
  • 别名表：搜索 恩希欧迪斯 会命中银灰；搜索 阿米娅(近卫) 命中阿米娅。
  • 剧透保护：关闭右上角开关后，未观看剧情的台词与深层档案展开（再次开启恢复折叠）。
  • 台词跳转：在出场剧情中点 ▶，进入「档案回放」——定位到该台词且不记录进度，可一键转为正常播放。
  • 打包/在线边界：将右上角「网络」切到离线——列表仍可用（包内种子索引），但详情需联网加载一次。这正是 §8.6 的行为。
