原型怎么玩约 5 分钟
  1. 选中即预览：点击舞台下方任意指令，画面停在该指令执行后的状态；End 回到分镜末态。
  2. 播放与传输：空格 播放/暂停，←/→ 按句跳，传输条可循环、倍速、全屏。
  3. 批量化：点击一条后 Shift 连选、Ctrl 增减；批量条可改说话人、复制、删除。
  4. 舞台直编：拖动立绘或舞台文字，接近中线会自动吸附；右侧检查器数值同步。缩放按钮可放大舞台。
  5. 多端工作区：桌面端提供编排、演出、剧本（对白表格）、交付四工作区；右上角可切“手机”预览精简形态（演出主视图 + 轻分镜切换 + 检查定位）。
  6. 路线图联动：点界面上的 P0/P1/P2 徽标或顶部“路线图”，都能打开分期面板并定位到对应区域；切换“阶段视图”可预览只交付 P0 时的界面。

原型数据为示意，不会真正导出文件；所有编辑仅在当前页面内存中生效，刷新即重置。
